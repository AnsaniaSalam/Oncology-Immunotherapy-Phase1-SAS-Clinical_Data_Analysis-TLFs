# Phase 1 Trial of Intralesional Immunotherapy with Active Drug Vaccine in Advanced Merkel Cell Carcinoma or Cutaneous Squamous Cell Carcinoma

## Project Overview

This portfolio project uses SAS to analyze clinical trial data and create tables, listings, and figures (TLFs) for a Phase 1 oncology immunotherapy study.

## Project Status

**In progress.** Most planned outputs have been prepared. Three tables remain in progress; one is being debugged because its output does not yet match the expected result.

## CDISC Data Standards and Input Datasets

The project materials include **CDISC-based SDTM and ADaM data**. SDTM materials were provided as part of the project. The TLF programs use these ADaM datasets:

- **ADSL** — subject-level data and treatment/population counts
- **ADAE** — adverse events
- **ADLB** — laboratory results
- **ADVS** — vital signs
- **ADRS** — response data
- **ADTTE** — time-to-event data
- **ADEFF** — efficacy data

The datasets are not included in this repository.

## Tools

- SAS Studio
- Base SAS 9.4_M8
- ODS RTF
- PROC REPORT, PROC SUMMARY, PROC FREQ, PROC LIFETEST, and PROC SGPLOT

## Repository Contents

- SAS programs for tables, listings, and figures
- Selected outputs approved for public sharing

## Running the Programs

The programs require the corresponding input ADaM datasets and may need path updates for another SAS environment. Since the input datasets are not included, the programs cannot be run from this repository alone.

## Data and Confidentiality

Project materials were provided for student training. No participant-level datasets are included. Only programs and outputs approved for public sharing should be added to this repository.
