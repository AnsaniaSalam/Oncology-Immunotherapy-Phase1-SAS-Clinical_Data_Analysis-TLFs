# Oncology-Immunotherapy-Phase1-SAS-Clinical-Data-Analysis-TLFs
SAS clinical trial data analysis for a Phase 1 Trial of Intralesional Immunotherapy in patients with Advanced Merkel Cell Carcinoma or Cutaneous Squamous Cell Carcinoma. Programs produce tables, listings, and figures (TLFs) using CDISC-based ADaM datasets: ADSL, ADAE, ADLB, ADVS, ADRS, ADTTE, and ADEFF. SDTM materials were provided.
