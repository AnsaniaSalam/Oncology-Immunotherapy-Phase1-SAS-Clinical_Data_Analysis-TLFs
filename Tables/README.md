# Tables

SAS programs for generating clinical study tables.

Programs currently included:

- T_14_1_1 — Subject disposition
- T_14_1_2 — Demographics: age
- T_14_1_3 — Demographics: sex and race
- T_14_1_4 — Treatment-emergent adverse events
- T_14_1_5 — Changes in vital signs
- T_14_1_6 — Laboratory shift table
- T_14_1_7 — Objective response rates (in progress)
- T_14_1_8 — Time-to-event analysis (in progress)
- T_14_1_9 — Follow-up time analysis (in progress)

Input ADaM datasets are not included. See the main README for project details and data-use notes.
