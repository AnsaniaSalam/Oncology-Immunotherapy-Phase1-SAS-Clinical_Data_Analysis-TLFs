# Figures

SAS programs for generating clinical study figures.

Programs currently included:

- F_16_2_1_1 — Mean and Standard Error Plot
- F_16_2_1_2 — Waterfall Plot of Patient-wise Change in Tumor Size per Visit
- F_16_2_1_3 — Spaghetti Plot of Tumor Size Over Time by Patient
- F_16_2_1_4 — Forest Plot of Effect Sizes Based on Parameter
- F_16_2_1_5 — Kaplan–Meier Survival Plot

## Software

SAS Studio using Base SAS 9.4_M8.

## Input datasets

The programs use ADAM.ADRS_SCORE, ADAM.ADTR, ADAM.FOREST, ADAM.ADTTE, and ADAM.ADSL. The datasets are not included in this repository.

See the main README for project details and data-use notes.
